# Review and Quality Assurance

Each lesson should be reviewed before translation or publication.

## Review checklist

- [ ] The problem statement is unambiguous.
- [ ] The problem has a correct and verified answer.
- [ ] Every step of the solution is logically valid.
- [ ] The explanation is appropriate for grades 4–6.
- [ ] Hints support discovery without revealing the answer too early.
- [ ] Alternative solutions are correct, if included.
- [ ] Common mistakes are realistic and clearly explained.
- [ ] The Persian text is clear and consistent.
- [ ] The German translation is mathematically equivalent and idiomatic.
- [ ] Sources and adaptation notes are recorded where relevant.

## Status labels

Suggested labels for lesson files: Draft, In Review, Revised, Approved, Translated, Published.

A lesson is not considered approved merely because a draft exists.
