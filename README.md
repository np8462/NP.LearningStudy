# NP.LearningStudy

A learning, studying, and teaching workspace.

## Current structure

- `MathOlympiad.Primary 4to6/` — a multilingual, step-by-step mathematics olympiad preparation project for primary-school learners in grades 4–6.

## Repository workflow

- The `main` branch is the only branch for the current documentation-first phase.
- Experimental or application-development branches may be introduced later, if the project evolves into software or an Android application.
- Markdown (`.md`) files are the canonical editable source.
- Word and PDF documents are publication outputs, generated only after the corresponding content has been reviewed and approved.

## Languages

Persian is the authoring language. German and other translations will be prepared from approved Persian source material and reviewed for age-appropriate mathematical terminology.
